DBMS Assignments – MySQL

About This Repository

This repository contains five Database Management Systems (DBMS) assignments completed as part of academic coursework. The assignments focus on understanding and implementing SQL queries using MySQL.

Each assignment is organized separately with properly numbered questions and their corresponding SQL solutions for easy navigation and reference.

Assignment Details

Topics covered:

- CREATE TABLE statements
- Primary Keys
- Foreign Keys
- UNIQUE Constraints
- AUTO_INCREMENT
- Composite Keys
- Database Integrity Constraints

Assignment 2 – Basic SQL Queries

Topics covered:

- SELECT Statements
- Column Aliases
- DISTINCT
- ORDER BY
- Aggregate Functions
- String Functions
- Mathematical Operations

Assignment 3 – Filtering and Conditional Queries

Topics covered:

- WHERE Clause
- BETWEEN and NOT BETWEEN
- IN and NOT IN

- Sorting and Filtering Records
- Pattern Matching

Assignment 4 – Aggregate Functions and GROUP BY

Topics covered:

- COUNT()
- SUM()
- MIN() and MAX()
- AVG()
- GROUP BY
- HAVING Clause

Assignment 5 – SQL Subqueries

Topics covered:

- Single-row Subqueries
- Multiple-row Subqueries

- Salary Comparisons
- Department-wise Comparisons

How to Use This Repository

1. Clone or download this repository.
2. Open the required assignment folder.
3. Open its "solutions.sql" file.
4. Copy the SQL queries into MySQL Workbench or another MySQL-compatible client.
5. Execute the queries to view the results.

Note: Some queries require the HR sample database, including tables such as "employees", "departments", and "jobs". Ensure the required database and tables are available before execution.
